Zombie Invasion

GitHub Link
Releases

An FPS tower defense game where you defend your base from waves of invading zombies. The game features a variety of purchasable items and weapon upgrades, multiple difficulty levels, and boosts that are granted periodically throughout the game that offer utility or even augment the player's weapons.

I developed this game from scratch in Unity, and I created all of the assets myself. The 3D models and animations were made in Maya. This was the first big game I've made in Unity. Some notable features that I implemented include a zombie targeting system that makes use of Unity's NavMesh system, an inventory system that allows the player to purchase, upgrade, and boost items and seamlessly swap between items, and an aiming and collision detection system for the sword and gun. I designed this game based on features from other games that I enjoy playing, such as League of Legends, Minecraft, and Roblox.



Tower Defense Game

GitHub Link

A tower defense game where you defend against waves of enemies by placing towers on the map. The game features many different enemies with different strength levels and a variety of towers with unique attacks and upgrades.

I developed this game entirely in Java, using the Java Swing library for the GUI. Some notable features that I implemented include a robust UI system that includes tower placement, a shop for towers, and info on tower upgrades and enemy stats, a targeting system for towers that allows the player to switch target priorization, and a sound system. The sounds were taken from royalty-free sound libraries. I designed this game based on Bloons Tower Defense.



Space Robot Game

GX Games Link

A platformer game where you play as a robot trying to escape a hostile world filled with enemies and obstacles as quickly as possible. This game features three different enemy types with unique behaviors, power ups to help the player, an ability that allows the player to teleport to their position from two seconds before, and multiple difficulty levels.

I developed this game in GameMaker for the University of Rochester Intro to Video Game Design summer program. Some notable features that I implemented include three different enemy behaviors: standing still and randomly attacking, patrolling and attacking when the player is visible and in range, and actively chasing/kiting the player, the teleportation ability that required keeping track of the player's position over time, and a power up system that gives the player temporary boosts to different stats. I also added coins to the game that acts as a bonus challenge for the players to collect. One cool mechanic is that the player maintains their velocity when they teleport, allowing them to extend their jumps with the ability to reach areas that would otherwise be inaccessible.



Chess

GitHub Link

A chess application where you can play on one or two devices, allowing players to play in-person or online. The application allows players to see the game notation, view previous moves, take back moves, and save and load games from files.

This application was developed in Java using the Java Swing library for the GUI. Some notable features that I implemented include the notation system, the save/load system, the ability to take back moves, and the general chess logic. The server-client connection system and the corresponding GUI was created as part of a group project for my AP CS class.



Snake Game

GitHub Link

The classic snake game where the player controls a snake that grows longer as it eats food, and the player must avoid colliding with the walls or themself.

I developed this game in Java using the Java Swing Library for the GUI. A notable feature that I implemented was the drawing of the snake's body, and required keeping track of the direction and position of each segment of the snake's body, and drawing the snake as it moved between positions with intermediate drawing frames. The sound were taken from royalty-free sound libraries.
